# Лендинг «Легенда Тропарёво»

Одностраничный сайт бильярдного клуба. Срок — 24 октября. Платформа — Битрикс24 (Сайты).

```
site/
  index.html          лендинг
  politika.html       политика обработки ПДн, согласие, cookie
  404.html            страница ошибки
  robots.txt, sitemap.xml
  favicon.ico, favicon.svg, apple-touch-icon.png
  assets/css/style.css, assets/js/main.js   без библиотек, ~31 КБ вместе (до gzip)
  assets/img/         логотипы (тёмный/светлый фон), эмблема, OG-картинка
tools/make_assets.py  пересборка логотипов и иконок из исходников заказчика
```

Локальный просмотр: `cd site && python3 -m http.server 8931` → http://localhost:8931

Всё, чего нет в брифе, помечено на странице оранжевым `[заполнить]` / `[подтвердить]` (класс `.todo`, фото — блоки `.ph`). Перед публикацией в коде не должно остаться ни одной такой метки.

## Решения «на усмотрение исполнителя»

| Вопрос | Решение | Почему |
|---|---|---|
| Название | «Легенда Тропарёво» | Так написано в логотипе. Сохраняет узнаваемость «Легенды» и не путается с клубом на Пятницком шоссе. |
| Заголовок первого экрана | «Бильярдный клуб в Тропарёво, где игра на первом месте» | Главное отличие из брифа («мы не бар с бильярдом») плюс гео-запрос «бильярдный клуб Тропарёво» в H1. |
| Дизайн | Уникальный, собранный из блоков Битрикс24 | Шаблоны Битрикс24 типовые и не передают премиальность. Для одной страницы свой дизайн почти не дороже, а фирменный стиль legendbc.ru (графит, золото #C2A566) сохраняется в более лёгкой подаче. |
| Куда идут заявки | CRM Битрикс24 (лиды) + уведомление на info@legtrop.ru | Клуб уже работает на Битрикс24: заявка сразу становится лидом с ответственным, приходит push в мобильное приложение администратору и не теряется в почте. |
| Поля форм | Бронь: имя, телефон, дата, время, тип стола. Школа: имя, телефон, взрослый/ребёнок, уровень. Турнир: имя, телефон, день. | Минимум полей: остальное администратор уточнит по телефону. Короткая форма — больше заявок. |
| Метрика | Загружается после «Принять» в cookie-баннере | Безопасно с точки зрения 152-ФЗ. Если нужна полная статистика без согласия — поменять в `main.js` одну строку (вызывать `loadMetrika()` сразу). |

## Сборка на Битрикс24

1. **Сайт** → Создать сайт → пустой шаблон. В настройках сайта подключить домен (CNAME/A-запись у регистратора по инструкции Битрикс24).
2. **Стили и скрипт**: Настройки сайта → «Свой HTML/CSS» → вставить содержимое `style.css` в `<style>` и `main.js` в `<script>`. Иконки и логотипы загрузить в «Диск» или блок «Изображение» и заменить пути `/assets/img/...`.
3. **Секции**: каждую `<section>` из `index.html` вставить отдельным блоком «HTML-код» (раздел «Другое»). Так можно редактировать, скрывать и менять местами блоки по отдельности. Цены — в обычной HTML-таблице: чтобы поменять цену, достаточно исправить число.
4. **Формы**: в CRM → «CRM-формы» создать 3 формы (Бронь стола, Школа, Турнир) с полями из таблицы выше и обязательным соглашением (текст — раздел 9 в `politika.html`). Встроить их код вместо `<form>` в модальном окне и блоке брони. Цели Метрики для CRM-форм уже ловятся в `main.js` (событие `b24:form:submit`, тип определяется по названию формы — в названии должны быть слова «школ» / «турнир»).
   Альтернатива — оставить HTML-формы и указать `CONFIG.formEndpoint` (свой обработчик). Входящий вебхук Битрикс24 напрямую из браузера не вызывать: это открывает доступ к CRM.
5. **SEO**: в настройках сайта — title, description, favicon, robots.txt (из `site/robots.txt`), включить карту сайта; 404 — отдельная страница сайта из `404.html`, назначить её страницей ошибки.
6. **Метрика**: создать счётчик, номер вписать в `CONFIG.metrikaId` (`main.js`). Цели типа «JavaScript-событие»:
   - `form_booking` — **главная цель**, отправлена бронь;
   - `form_school`, `form_tournament` — отправлены формы;
   - `open_booking`, `open_school`, `open_tournament` — открыта форма;
   - `click_phone`, `click_messenger`, `click_email`, `click_route` — клики по контактам.
7. **Вебмастер**: добавить сайт, код подтверждения вписать в `<meta name="yandex-verification">`, отправить sitemap.xml.
8. **301-редиректы** не нужны: сайт новый, старых адресов нет.
9. Отправить уведомление об обработке ПДн в Роскомнадзор (pd.rkn.gov.ru), если ООО его ещё не подавало. Политику перед публикацией стоит показать юристу.

## Что нужно от заказчика

**Контакты:** телефон (для кнопки «Позвонить» — везде стоит `tel:+7XXXXXXXXXX`), часы работы, ссылки на мессенджеры и соцсети, ближайшее метро (Яндекс Карты показывают «Тропарёво» в 610 м — подтвердить), ОГРН.

**Цены и расписание:** прайс в `legend_uslugi_i_ceny.xlsx` собран с legendbc.ru, это клуб на Пятницком шоссе. Нужно подтвердить для Тропарёво: цены, есть ли столы №3 и №5, TV-стол, VIP 1/VIP 2, сервис кия и расписание турниров. Субботний коммерческий турнир с legendbc.ru не переносил — его нет в прайсе.

**Акции:** условия сертификатов, абонементов, бонусов, промокодов, текущая сезонная акция.

**Школа:** стоимость, расписание, имена и регалии тренеров.

**Бар и кухня:** ссылка на меню (PDF), 2–3 фирменных блюда.

**Фото** (генерировать нельзя, места размечены на странице):
главное — Бауров и Сталев в зале (после согласования с ними); общий план зала; стол и шары крупно; VIP-зона; бар; блюдо; Бауров с учеником.
Формат: JPG/WebP, по длинной стороне 1600–2400 px. Перед вставкой сжать (`cwebp -q 78`) и вставить как `<img src="..." width height loading="lazy" alt="...">` внутрь соответствующего `.ph` (у главного фото — без `loading="lazy"`).

**Домен:** везде указан `legtrop.ru` (по почте info@legtrop.ru). Если домен другой — заменить в `index.html`, `politika.html`, `robots.txt`, `sitemap.xml`.
